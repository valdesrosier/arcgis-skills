# Inline the destructive-operation guard into each skill for distribution

Supersedes [ADR-0004](0004-destructive-guard-shared-policy.md). To make the skills installable via `npx skills add` — which locates skills by their `SKILL.md` and would drop a bare shared file that has none — the destructive-operation guard is inlined into `js-sdk` and `python-notebook` rather than kept in a shared `_shared/destructive-operations.md`. Each skill is now self-contained and survives being copied individually by the CLI. The trade-off — two copies of the same short policy instead of one source of truth — is accepted because self-contained distribution matters more than DRY for a published skill set, and the guard is still invoked as an explicit step, retaining the deterministic firing ADR-0004 established.
