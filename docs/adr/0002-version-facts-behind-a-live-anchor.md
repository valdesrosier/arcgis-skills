# Version facts live behind a live URL anchor, never baked into a SKILL.md

ArcGIS version relationships change over time — e.g. the Experience Builder production build command moved from `npm run build:prod` to `npm run build:for-download`, and its output moved from `client/dist-prod/widgets` to `client/dist-download/widgets`, at release 1.17 — so any `SKILL.md` that hardcodes a version-specific fact becomes confidently wrong later. Each version-needing skill therefore encodes the *procedure* for discovering the version and points a context pointer at the live Esri version-matrix URL, which stays the single source of truth for the Enterprise↔SDK↔Calcite↔Arcade mapping. `exb-widget` additionally keeps a local `VERSIONS.md` for ExB-only facts not on that matrix (Node/pnpm gates, ExB-release↔SDK mapping, the compiled-in-version rule), each stamped with an instruction to re-verify against Esri's release-versions page.
